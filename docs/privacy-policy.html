GTab Privacy Policy

Last updated: April 30, 2026

GTab ("the Extension") is a Chrome browser extension that provides a customizable new tab page. This policy explains in detail what Google user data is accessed, how it is used, and how it is protected, in compliance with the Google API Services User Data Policy.

Summary: GTab does not operate any servers. All Google user data stays on your device and is used exclusively to display information in your new tab page. We do not share, sell, or transmit your data to any third party.

1. Google User Data Accessed

GTab accesses the following Google user data only when you explicitly enable the corresponding widget. All access is opt-in and disabled by default.

WidgetOAuth ScopeExact Data AccessedData NOT Accessed
Gmail Widget gmail.metadata Sender name, sender email address, subject line, and received date of recent emails (metadata only) Email body, attachments, message content, labels, drafts, sent mail, or any other Gmail data
Google Calendar Widget calendar.readonly Event title, start/end time, and location of upcoming calendar events Attendee lists, meeting links, event descriptions beyond display, private calendars you have not granted access to
Google Tasks Widget tasks Task titles, due dates, and completion status from your task lists Notes fields are not displayed; no access to deleted tasks or task history

User identity data (openid, email, profile) is accessed solely to display your name and profile picture in the extension header and to associate your local settings with your Google account.

2. How We Use Google User Data

Each piece of Google user data is used for a single, specific purpose:

  • Gmail metadata (sender, subject, date): Displayed in the Gmail widget on your new tab page so you can see recent emails at a glance without opening Gmail. The data is rendered locally in the browser and is never processed beyond display.
  • Calendar events: Displayed in the Calendar widget to show your upcoming schedule on your new tab page.
  • Tasks: Displayed and managed in the Tasks widget. You can mark tasks complete directly from the new tab page; changes are written back to Google Tasks via the Tasks API.
  • Identity (name, email, profile photo): Shown in the extension UI for personalization. Not used for any other purpose.

GTab does not use any Google user data for advertising, analytics, profiling, or training AI/ML models. GTab's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Data Sharing

GTab does not share Google user data with any third party. Specifically:

  • No Google user data is sent to GTab's developer or any server controlled by GTab.
  • No Google user data is sold, rented, or licensed to any party.
  • No Google user data is used for advertising, remarketing, or audience building.
  • No analytics or crash-reporting services receive Google user data.

The only parties that receive your Google data are Google's own APIs (googleapis.com), when the Extension makes API calls on your behalf to fetch your own data.

4. Data Storage and Protection

  • Local storage only: All data fetched from Google APIs is stored locally on your device using Chrome's sandboxed chrome.storage.local API. This storage is isolated to the GTab extension and is not accessible by other extensions, websites, or applications.
  • OAuth tokens: Google OAuth access tokens are stored in chrome.storage.local and are used exclusively to make authenticated API requests on your behalf. Tokens are never transmitted to any server other than Google's own OAuth endpoints.
  • No remote servers: GTab has no backend infrastructure. There are no databases, cloud functions, or servers that store or process your data.
  • Cache: API responses may be cached locally (e.g., weather data cached for 30 minutes) to reduce API calls. Cached data is stored in chrome.storage.local and is subject to the same protections.

5. Data Retention and Deletion

Retention

Google user data fetched by GTab is held in local browser storage only for as long as you use the Extension. Data is refreshed on each new tab load; cached data expires automatically (typically within 30 minutes to 1 hour depending on the widget).

Deletion

You can delete all locally stored GTab data at any time through any of the following methods:

  • Within the Extension: Open GTab Settings → Account → Sign Out. This clears the stored OAuth token and all cached Google data.
  • Uninstall: Uninstalling the GTab extension from Chrome automatically deletes all chrome.storage.local data associated with the Extension.
  • Browser settings: In Chrome, navigate to Settings → Privacy and security → Clear browsing data → Site data and clear extension data.

Revoking Google Access

You can revoke GTab's access to your Google account at any time by visiting Google Account Permissions and removing GTab. After revoking access, the Extension will no longer be able to fetch Google data until you re-authorize.

6. Third-Party Services (Non-Google)

GTab communicates directly with the following additional services. None of these services receive Google user data:

  • Open-Meteo (api.open-meteo.com) – Weather data. Only approximate GPS coordinates (latitude/longitude) are sent. No personal identifiers.
  • Nominatim / OpenStreetMap (nominatim.openstreetmap.org) – Reverse geocoding to convert coordinates to a city name. No personal identifiers.
  • Yahoo Finance / Alpha Vantage – Stock price data. Only stock ticker symbols are sent. No personal identifiers.
  • Spotify API (api.spotify.com, accounts.spotify.com) – If you set up the Spotify widget using your own Spotify Developer App credentials, the Extension communicates directly with Spotify's API to show currently playing track and playback controls. Your Spotify OAuth token is stored locally and only sent to Spotify's official API endpoints.

These services are governed by their own privacy policies and are used only for the purpose of displaying data in their respective widgets.

7. Chrome Permissions Justification

GTab requests only the minimum permissions required for its functionality:

  • storage – Saves your widget layout, shortcuts, and preferences locally.
  • identity – Authenticates with Google to access Calendar, Gmail, and Tasks widgets.
  • activeTab, tabs – Used to open shortcuts and manage tab navigation. No tab content is read or transmitted.
  • contextMenus – Adds a right-click option to save shortcuts from any page.

8. Children's Privacy

GTab is not directed at children under 13 and does not knowingly collect data from children. If you believe a child has used the Extension, please contact us so we can ensure any locally stored data is removed.

9. Changes to This Policy

We may update this policy to reflect changes in the Extension's functionality or to comply with updated requirements. The "Last updated" date at the top of this page will reflect any changes. For significant changes, a notice will be included in the Extension's update notes.
